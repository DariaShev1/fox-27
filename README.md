# С днём рождения, Хитрый Рыжий Лис

Одностраничный сайт-поздравление для Антона. Только HTML, CSS и чистый JavaScript, без сборки.

```
index.html      разметка и вся SVG-графика
style.css       стили (mobile-first)
script.js       объект CONTENT со всеми текстами + логика
images/         твои фото + og-cover.png (превью для мессенджеров)
audio/          сюда положи track.mp3
.nojekyll       чтобы GitHub Pages отдавал файлы как есть
```

## 1. Тексты

Все тексты лежат в объекте `CONTENT` в самом начале `script.js`. Каждый блок подписан комментарием
на русском. Меняй только то, что стоит в кавычках.

Что обязательно заменить (поиск по `[`):

| Метка | Где |
|---|---|
| `[ТВОЁ ИМЯ]` | `signature`, подпись под письмом |
| `[ПОДПИСЬ ПРО ПАВЛОДАР]`, `[ПОДПИСЬ К ФОТО]` | `pavlodar` |
| `[ПОДПИСЬ ПРО ДЕТСТВО]`, `[ПОДПИСЬ]` под детскими фото | `childhood` |
| `[ПОДПИСЬ ПРО ЕГО ФУТБОЛ]` | `field.text` |
| `[ПОДПИСЬ ПРО РАБОТУ]` | `lab.text` |
| `[ДОПИШИ СВОЁ]` | записки к книгам в `worlds.books` и описание колы в `cola.flavor` |
| `[ПОЖЕЛАНИЕ 1]` … `[ПОЖЕЛАНИЕ 6]` | `questLog.items`: там же заголовок квеста и статус |
| `[НАЗВАНИЕ ТРЕКА]`, `[ПОДПИСЬ ПРО МУЗЫКУ]` | `music` |
| `[ГЛАВНЫЙ ТЕКСТ]` | `final.text` |

Правила:
- Там, где значение — массив строк (`text: ['…', '…']`), каждая строка становится отдельным абзацем.
- Внутри текста используй «ёлочки». Прямой апостроф `'` сломает строку.
- Статус квеста: `'active'` («Активно»), `'new'` («Новое задание»), `'legendary'` («Легендарное»).
- Цвета шарфа «Иртыша» задаются в `field.irtyshColors`. По умолчанию стоят синий и белый.
- «Лаборатория»: ответы терминала лежат в `lab.uart`, код прошивки — в `lab.firmware` (поздравление спрятано в комментариях),
  «история версий» Антона — в `lab.gitLog`.
- Достижения: названия и описания — в `achievements.list`. `secret: true` прячет достижение под «???», пока его не получат.
  Прогресс сохраняется в браузере. После своих тестов нажми «Сбросить» в «Зале трофеев», чтобы не отправить Антону уже открытые достижения
  (у него в браузере прогресс и так начнётся с нуля).

## 2. Фото

1. Положи файлы в папку `images/`, например `images/pavlodar-1.jpg`.
2. Впиши пути в `CONTENT.pavlodar.photos`, `CONTENT.childhood.photos` (детские, по умолчанию ждёт `images/child-1.jpg` … `child-4.jpg`) и `CONTENT.final.photos`:
   ```js
   photos: [
     { src: 'images/pavlodar-1.jpg', caption: 'Подпись под фото' },
   ],
   ```
3. Если файла нет или путь с опечаткой, на его месте будет аккуратная рамка «Место для фото» с путём.
   Фото «хроник» в финале можно убрать совсем: `photos: []`.

Советы: JPG до 1600px по длинной стороне и до ~400 КБ, иначе с мобильного интернета будет грузиться долго.
Имена файлов пиши латиницей без пробелов. На GitHub Pages регистр букв важен: `Foto.JPG` ≠ `foto.jpg`.

## 3. Музыка

Положи песню Присциллы в `audio/track.mp3` (название уже вписано в `CONTENT.music.title`).
Автозапуска нет: музыка включается кнопкой в плеере внизу или кнопкой «Попросить барда спеть» в «Таверне».
Пока файла нет, в плеере будет написано «Нет файла audio/track.mp3».
На iPhone громкость регулируется только кнопками телефона, поэтому там ползунок громкости спрятан.

## 4. Если правки не видны

К `style.css` и `script.js` в `index.html` дописана версия: `style.css?v=6`. Браузер кэширует эти файлы,
поэтому после своих правок увеличь число в обеих строках (`?v=7`, `?v=8`…) — тогда все, включая Антона,
получат свежую версию. Для себя можно просто нажать Ctrl+F5.

## 5. Проверить локально

Микрофон и часть функций работают только через http(s), поэтому не открывай файл двойным кликом, а запусти сервер.
Сервер раздаёт ту папку, из которой его запустили, поэтому папку проекта указывай явно:

```bash
python -m http.server 8000 --bind 127.0.0.1 --directory "D:\project-for-Anton"
```

Потом открой http://localhost:8000. Посмотреть мобильную версию можно в DevTools (Ctrl+Shift+M), ширина 360px.

## 6. Деплой на GitHub Pages

1. Создай репозиторий на GitHub, например `fox-27`. Он может быть публичным: в `<head>` уже стоит
   `noindex, nofollow`, так что поисковики страницу не проиндексируют. Но саму ссылку сможет открыть любой, у кого она есть.
2. Загрузи содержимое папки в корень репозитория: через «Add file → Upload files» на сайте или так:
   ```bash
   git init
   git add .
   git commit -m "Сайт для Антона"
   git branch -M main
   git remote add origin https://github.com/USERNAME/fox-27.git
   git push -u origin main
   ```
3. Открой в репозитории **Settings → Pages**. В разделе *Build and deployment* выбери *Source: Deploy from a branch*,
   *Branch: main*, папку `/ (root)` и нажми **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://USERNAME.github.io/fox-27/`.

### Превью ссылки в мессенджерах

В `index.html` в метатегах `og:url` и `og:image` замени `USERNAME` и `REPO` на свои
(должно получиться `https://USERNAME.github.io/fox-27/images/og-cover.png` с твоим логином). Картинка `images/og-cover.png` уже лежит в проекте.
Telegram кэширует превью. Если ссылку уже отправляли до правки, обнови превью через бота @WebpageBot.

## Что где на странице

1. Вход: медальон с лисом. Клик открывает сайт и разрешает звук.
2. Торт: 27 свечей. Задуваются кликом или кнопкой «Дунуть по-настоящему», которая слушает микрофон.
   Если браузер не даёт доступ к микрофону, кнопка просто исчезает и остаются клики.
3. Карта: пять точек, каждая плавно прокручивает к своему разделу.
4. Павлодар: силуэт набережной, счётчик рилсов, галерея.
   Сразу за ним «Лисёнок»: детские фото в виде полароидов на скотче, по два в ряд на телефоне.
5. Поле: пенальти на canvas, 5 ударов. Верхние углы вратарь берёт хуже, но можно попасть в штангу. Шарфы.
6. Лаборатория: плата со светодиодом (кнопка USER переключает светодиод на 27 миганий в минуту, RESET возвращает 60) и панель как в IDE с тремя вкладками:
   «Терминал» (UART с командами `status`, `measure`, `flash`, `git status`, `wish`), «Прошивка» (`main.c`), «История» (`git log`)
   и «Анализатор» — загадка: захват линии TX, который нужно правильно декодировать (ничего не написано прямо: скорость 115200 вводится вручную — её надо посчитать из BRR = 0x16D при PCLK1 = 42 MHz или измерить по линейке; формат кадра 8E1 — по числу битов в кадре или из заголовка терминала; ASCII в декодере нет, байты UTF-8 надо перевести самому).
   Ответ — `lab.analyzer.answer` («ты гений»), награда — `lab.analyzer.secret`. Под платой — OLED-дисплей на проводах I2C,
   экраны листаются сами и по нажатию (тексты в `lab.oled`).
7. Миры: полка с книгами (клик по корешку вытягивает книгу), карточка задания Diablo 4 и предмет из инвентаря —
   «Эликсир шипучей бодрости» (кола). Кнопка «Выпить» наклоняет бутылку и убавляет уровень, после четырёх глотков можно достать новую.
8. Журнал заданий: шесть пожеланий-квестов.
9. Таверна: камин, бард и песня Присциллы (трек в `CONTENT.music`), плеер закреплён внизу экрана.
   Ниже доска заказов — шуточные объявления в `music.board`.
   Затем «Зал трофеев»: 16 достижений (3 секретных) в виде сетки медалей, по нажатию — за что медаль.
   Они всплывают плашкой сверху, когда Антон что-то делает на странице.
   Если собрать все, снова летит конфетти.
10. Финал: главное письмо, сундук с легендарным лутом (подарок описан загадочно, тексты в `CONTENT.loot`),
    медальон, дата и счётчик дней дружбы.

При включённой в системе настройке «Уменьшить движение» (prefers-reduced-motion) анимации отключаются,
а конфетти не запускается.
